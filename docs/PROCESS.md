# Процесс внесения и публикации данных

## Правило #1: Только `data-new.json`

**Запомни:** редактировать нужно ТОЛЬКО `data-new.json` — это WIP (работа в процессе) текущей недели.

`data.json` — это **опубликованный факт**, его меняет только автоматика. Если внести туда данные вручную, они пересвишут при следующей еженедельной публикации (понедельник 06:00).

**Неправильно:**
```
Сергей пишет в data.json → данные тут до понедельника → workflow перезапишет
```

**Правильно:**
```
Сергей пишет в data-new.json → workflow в понедельник 06:00 автоматически:
  - архивирует data.json → archive/week-NN.json
  - копирует data-new.json → data.json (публикует)
  - генерирует новый data-new.json для следующей недели
```

## Способы внесения данных

### 1️⃣ Через бота @reacto_robot (рекомендуется)

**Преимущества:**
- Автоматическое накопление (дописывание через ` · `)
- Контекст диалога сохраняется
- Подтверждение перед сохранением
- Режим правки ($set) для исправлений

**Пример:**

```
Ты:      Какой план у АИ.П26.01 на следующую неделю?
Бот:     Уточни, пожалуйста — что добавить в дашборд?
Ты:      Согласовать БТ с заказчиком, провести встречу
Бот:     📋 Превью перед сохранением:
         🔹 АИ.П26.01 [активный]
           План на следующую неделю: Согласовать БТ с заказчиком, провести встречу
         Ответьте да — сохранить, изменить — скорректировать
Ты:      да
Бот:     ✅ АИ.П26.01 — план добавлен
```

**Команды бота:**
- `/id` — показать ID чата и пользователя
- `/msg <chat_id> <текст>` — отправить сообщение в группу (только админ)

### 2️⃣ Через прямые коммиты (экстренные случаи)

Если нужно внести много данных разом и нет времени на бот:

```bash
# Отредактируй data-new.json в редакторе
git add data-new.json
git commit -m "feat: update week data — owner/plan/risks for pilots"
git push
```

**Но потом:**
- Напиши /notify в группу что обновил
- Следующий раз используй бота

## Поля пилота — что и когда менять

| Поле | Как внес | Как меняется | Пример |
|------|----------|--------------|---------|
| `id`, `name`, `stage` | Один раз в начале | Не меняется | АИ.П26.01 |
| `owner` | Один раз, потом может меняться | Замена ($set) | А (Алексей) |
| `done` | Каждый день на протяжении недели | Дописывается через ` · ` | 05.07 — встреча · 06.07 — согласована БТ |
| `plan` | В конце недели (пятница–воскресенье) | Дописывается, очищается на понедельник | Старт тестирования · Провести интеграцию |
| `risks` | По ходу недели, когда появляются | Дописывается, очищается на понедельник | Заказчик медлит · Нужна ИБ-проверка |
| `artifact` | Накапливается всю неделю | Дописывается через ` · ` | БТ · Протокол встречи |

## На что обратить внимание

**✅ Хорошо:**
```json
{
  "id": "АИ.П26.01",
  "owner": "А",
  "done": "05.07 — Встреча с заказчиком",
  "plan": "Согласовать БТ",
  "risks": "Риски отсутствуют",
  "artifact": "Протокол встречи"
}
```

**❌ Плохо:**
```json
{
  "id": "АИ.П26.01",
  "done": "",                    // пилот в активных, но нет done — неинформативно
  "plan": "План из прошлой недели",  // не обновлено на текущую
  "risks": ""                    // пусто — просто удали, чем оставлять
}
```

## Еженедельный цикл

**Понедельник 06:00 МСК** — GitHub Actions:
1. Сравнивает `data-new.week` с `data.week`
2. Если `data-new` свежее → архивирует, публикует, генерирует шаблон
3. Очищает: `done`, `plan`, `risks` у активных; `done`, `plan`, `risks` у контрольных
4. Сохраняет `artifact` (справочное)

**Вторник–воскресенье** — оператор вносит данные в `data-new.json`

**Понедельник 06:00** — всё повторяется

## Что делать если ошибся

**Исправить текущую неделю:**
1. Напиши боту: "исправь" или "замени"
2. Бот переходит в режим правки ($set)
3. Ты отправляешь правильный текст целиком
4. Бот перезаписывает поле вместо дописывания

**Пример:**
```
Ты:   Исправь план для АИ.П26.01 — было неверно
Бот:  ✏️ Режим правки. Отправь исправленный текст целиком
Ты:   Провести встречу с заказчиком, согласовать БТ
Бот:  📋 Превью (режим замены):
       План на следующую неделю: Провести встречу...
       ✅ или нет?
Ты:   да
Бот:  ✅ Исправлено
```

## Доступ к боту

Бот работает в группе и в личке. В группе отвечает на:
- @mention: `@reacto_robot что нового?`
- Reply на сообщение бота
- Слова `реактор`, `reacto`

В личке отвечает на всё.
